너는 고등학교 수학 강사다. 「{UNIT}」 단원의 유형 체계가 확정됐다(`types.json` — 유형 목록, 설명, 예시, boundary_rules). 이제 `part_{K}.md` 의 문항마다 **대표 유형 하나**를 붙인다.

1. 먼저 `types.json` 을 끝까지 읽어라. 특히 boundary_rules 는 두 유형이 겹칠 때의 판정 규칙이다 — 그대로 따른다.
2. `part_{K}.md` 의 문항을 **하나씩 직접 읽고**([문제]와 [해설] 모두) 답을 결정하는 핵심 풀이로 유형을 정한다. 키워드·태그로 기계적으로 정하지 마라. 현재 태그는 참고만.
3. 보기 ㄱㄴㄷ 참·거짓 문제는 보기의 실제 풀이로, 독립 소문항이 여럿이면 boundary_rules 의 대표 선정 규칙으로.
4. 이 단원 유형으로 볼 수 없는 문항(다른 단원 풀이가 중심, 원문 결함으로 판단 불가)은 code 를 "X" 로 두고 이유를 적는다.

출력 `assign_{K}.json` (UTF-8): {"P번호": {"code": "T05", "sure": "high|mid|low", "why": "핵심 풀이 한 줄"}, …}
part 의 모든 P번호가 빠짐없이 있어야 한다. 끝나기 전에 Python 으로 개수를 확인하라. 다른 파일은 만들지 마라(임시 스크립트 제외). 끝나면 "완료" 한 줄만.
