# 변형 시험지 지시문 (붙여 넣기용)

> 〈 〉 안만 바꿔서 쓴다.

---

〈원본 시험지: 2026년 시행 고3 9월 모의평가〉를 바탕으로 **변형 시험지 〈10〉세트**를 만든다.
각 세트는 원본과 같은 문항 수·배점·과목 구성이고, 세트마다 원본 n번 자리에 원본 n번의 변형이 들어간다.

## 1. 변형은 '숫자 바꾸기'가 아니다

원본 문항 하나에서 변형 〈10〉개를 만들 때, 아래 네 가지 방법을 **섞어서** 쓴다.
같은 원본에서 나온 변형끼리는 **서로 다른 방법 조합**이어야 한다.

1. **숫자 교체**: 숫자를 바꿀 때는 미지수의 위치도 옮긴다. 숫자는 따로따로 바꾸지 말고, 답이 깔끔하게 떨어지도록 **함께 설계**한다.
2. **연산·부호 교체**: A−B → A+B, p+q → p−q처럼 바꾼다. 발문 문장은 그대로 둬도 된다.
3. **묻는 방향 뒤집기**: 원본이 'A를 구하라'면 'A가 주어졌을 때 상수를 구하라'로 바꾼다.
4. **조건 갈아끼우기**: sinθ+cosθ → sinθcosθ, 직선 → 원처럼 바꾼다. 묻는 것도 따라 바뀌어도 된다('값' → '최댓값').

**배분:** 변형 10개 중 숫자 교체만 쓴 것은 **3개 이하**로 한다. 나머지는 2·3·4번 중 적어도 하나를 쓴다.

## 2. 유지할 것

- **핵심 풀이 원리:** 원본 문항이 평가하는 핵심 개념과 풀이 원리는 유지한다. 바꾸는 것은 그 원리를 쓰는 '상황'이다.
- **난이도:** 원본과 비슷하게 맞춘다. 4점 문항은 4점답게, 킬러 자리(공통 15·21·22번, 선택 29·30번)는 끝까지 어렵게 둔다.
- **범위:** 교육과정 밖의 개념이나 표기는 쓰지 않는다.

## 3. 금지 (지난 작업에서 실제로 나온 문제)

- **같은 원본에서 나온 변형끼리 최종 답이 같으면 안 된다.**
- **억지 계수 금지:** (40x−83)/12, 141/16처럼 답을 맞추려고 만든 지저분한 계수는 쓰지 않는다. 실제 시험지에 나올 만한 수로 다시 설계한다.
- **조건 구멍 금지:** 변형으로 조건이 바뀌면 교점 개수, 해의 개수, 범위가 원래와 같은지 **꼭 다시 확인**한다. 지난번에는 지수함수와 포물선의 교점이 2개에서 3개로 늘었는데, 문제와 해설이 2개를 전제하고 있었다.
- **답이 여러 개 금지:** 객관식 정답은 하나, 단답형 답도 하나여야 한다.

## 4. 표기와 문장

- **제목:** 「2026년 시행 고3 9월 모의평가 변형 01회」처럼 띄어 쓴다.
- **선택과목 번호:** 과목마다 23~30번을 다시 쓴다(미적분을 31번부터 잇지 않는다).
- **숫자와 근호:** 6×√3이 아니라 6√3으로, 분수 앞 음수는 −3/2로 쓴다.
- **정규분포표:** 표 형식으로 넣는다.
- **해설 문장:** 우리 고등학교 교재와 강사가 쓰는 말투로 쓴다. '입력의 변화량', '입력 범위', '보이는 문자 배열' 같은 번역투는 쓰지 않는다. 함수의 '정의역', '구간', 'x의 값의 범위'처럼 교과서 말로 쓴다.
- **해설의 근거:** 각 줄이 앞 줄에서 비약 없이 이어지게 쓴다. 식만 던지지 말고 근거 한 줄을 붙인다.

## 5. 끝내기 전에 할 것

1. **답 검산:** 모든 문항의 답을 해설과 따로 다시 계산해서 맞춘다. 가능하면 프로그램으로 확인한다(경우의 수는 전부 세기, 방정식은 수치로 풀기).
2. **세트 간 비교표:** 원본 문항별로 10개 변형이 각각 어떤 방법(1~4번)을 썼고 최종 답이 무엇인지 표로 만든다. 답이 겹치거나 숫자 교체만 쓴 것이 3개를 넘으면 다시 만든다.
3. **보고:** 결함 원본(원본 자체에 오류가 있던 문항)이 있었으면 따로 보고한다.

## 6. 작업 나누기

- 460문항을 한 번에 설계하지 말고, **원본 문항 하나씩** 맡긴다. 원본 1번의 변형 10개, 원본 2번의 변형 10개처럼 나눈다.
- 여러 작업자가 동시에 만들고, 세트로 묶는 것은 마지막에 한 번만 한다.

## 7. 변형 방향 메뉴 (실제 모의고사 → 내신 변형 109쌍에서 뽑음, 10/18)

대표가 문제를 주면 본 세션이 먼저 이 중 어울리는 방향 5~6개를 골라 보여 주고, 대표가 고른 방향으로 작업자에게 맡긴다.

- A1 숫자 연동 교체 — Σ(ka_k−6k²+2)=3n²+5n → Σ(ka_k−6k²+1)=2n²+3n
- A2 주어진 것↔미지수 자리 바꾸기 — |3x−1|<x+a 의 a 를 절댓값 안으로 / 고정 구간과 매개변수 구간 역할 교환
- B3 결과를 주고 원인 묻기 — 주축 길이→넓이 를 넓이 30→주축 길이로 / 교점→무게중심 을 무게중심→n 으로
- B4 같은 조건, 다른 값 묻기 — 기울기 대신 선분 길이 / f(2) 대신 f(1)
- B5 역수·대우로 묻기 — OH²/OP² → OP²/OH² / 명제의 대우
- C6 조건 강도 조절 — "정확히 4개"→"2개 이상" / |a_m|=2|a_(m+2)| → a_m=−2a_(m+2)
- C7 같은 정보를 다른 꼴로 — a₆=2 → a₄+a₅=30 / 인접 두 값 같음 → 세 값의 합
- C8 규칙 살짝 비틀기 — 3aₙ+1→3aₙ+2 / f∘g→g∘f / 쌍곡선 주축 x축→y축
- C9 부호·방향 뒤집기 — 좌우 반전(우극한→좌극한) / 부등호 반대
- C10 역할 맞바꾸기 — 연립의 x↔y / 가중치 1..n → n..1
- C11 같은 원리, 다른 함수·도형 — 3sin→5cos+중심 이동 / 할선→접선 / 프랙탈 규칙 교체
- D12 소문항 추가 — 넓이 + (2) 정사영 / 근 + 대칭식 값
- D13 빈칸형↔직접 묻기 — 증명 빈칸 2→3개, 또는 빈칸 없이
- D14 계산 경로 바꾸기 — 등차×등비 곱의 합 제거 / 역추적 단계 수 조절
- E15 식↔그래프 — 방정식의 두 근 → 그래프의 x절편 / 수직선 점 → 최대·최소
- E16 일반화 — 고정 수를 매개변수로, f(a) 로 정의해 여러 값
- F 오답 원인 파고들기(대표 방식) — −cx→+cx 로 예전 답이 틀리게 / 미분불가능점을 다 세면 틀리게

### 7-2. 고난도(난이도 5 이상) 문항에서 더 나온 방향 (전국연합 → 내신 876쌍, 10/18)

고난도 짝의 89%가 실제 변형이었다. 위 메뉴에 더해:
- G1 후속 계산 덧붙이기 — 원래 답을 구한 뒤 한 단계 더(보조량·최적화·추가 합산). 예: 각의 이등분선 AP 길이 → AP×(1/θ)
- G2 중간값으로 질문 줄이기 — 킬러의 뒷단계를 덜어내고 중간에 정해지는 값을 묻기(내신이 킬러를 쉽게 낼 때). 예: h(x)=|f(x)|+g(x) 킬러의 최종값 대신 접점 m 만 묻기
- G3 조건의 해석 경로 바꾸기 — 같은 관계를 다른 성질로 간접 제시해 새로 유도하게. 예: lim f(x)/(x²+2x−3)=1/4 → lim |f(x)−3|/(x−2)=k 가 존재
- G4 ㄱㄴㄷ 진위 판정으로 재구성 — 최솟값 계산을 풀이 중간의 극한·극값·후보 합 판정으로 쪼개기
- G5 유일해 ↔ 여러 후보 비교 — "최댓값은?"(후보 비교) ↔ 조건을 바꿔 하나로 정해지는 구성 "합은?"
- G6 최대 ↔ 최소 교체 — 부분집합의 가장 작은 원소의 합 → 가장 큰 원소의 합
- G7 해의 집계 방식 교체 — 같은 후보들에서 개수·합·곱·최댓값·전체 나열 중 묻는 것 바꾸기
- G8 경계·예외 조정 — 등호·끝점 포함 여부, 영점을 바꿔 경계 사례를 점검하게
- G9 추가 조건으로 후보 거르기 — 부호·함숫값·유일성 조건을 보태 여러 후보 중 하나만 남기기
- G10 명제의 범위 바꾸기 — '모든'↔'어떤', 판단 범위 교체
- G11 닮음·평행이동으로 재배치 — 도형·그래프를 비례 확대·축소하거나 좌표를 함께 옮겨 관계는 두고 수치만 새로
- G12 증명 요구 — 계산·진위 판단을 근거를 들어 증명하는 서술형으로

## 8. 실제 학생 오답 자료 (10/19)

`C:/selfmade/오답조사/real_errors.json` — 서울 학생 시험지 스캔 1,022장에서 확인한 실제 오답.
- `by_question["<source_db_id>#<문항번호>"]`: 그 원본 문항에서 실제로 틀린 학생의 필기 흔적·어긋난 곳
- `by_unit["<단원(공백 없이)>"]`: 그 단원에서 반복된 오답 원인(시험지 수 = 근거 학생 수)과 '함정이 작동하는 조건'
F 오답 원인 파고들기, '흔한 오답' 선지는 여기서 고른다. 해설만 보고 상상한 실수는 쓰지 않는다. 자료에 없으면 '추정'이라고 밝힌다.
변형 파이프라인은 `run.py ... --unit <단원> --src <source_db_id> --no <번호>` 로 주면 작업 폴더에 real_errors.md 를 만들어 준다.
