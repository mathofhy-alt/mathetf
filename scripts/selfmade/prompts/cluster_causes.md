너는 고등학교 수학 오답 분석가다. 이 폴더의 `items.json` 은 한 단원에서 **서울 학생들이 실제 시험지에 남긴 풀이 흔적**으로 확인한 오답 사례 목록이다(사례마다 exam=시험지, no=문항, type=문항 유형, work=학생 필기, diverge=어긋난 단계, evidence=근거, cause=원인 한 줄, confidence).

할 일: 같은 '오답 원인'끼리 묶어 원인 목록을 만들어 `catalog.json` 에 쓴다.

규칙
- 원인은 **사례에 적힌 근거로만** 만든다. 사례에 없는 원인을 상상해서 넣지 마라.
- 묶는 기준은 "학생이 어떤 생각·절차에서 어긋났나"다. 단순 '계산 실수'도 어디서(부호·분배·대입 등) 틀렸는지로 나눌 수 있으면 나눈다. 단, 사례가 1건뿐인 세부 원인을 억지로 만들지 말고 가까운 원인에 넣거나 '기타'로.
- 원인 이름은 강사가 학생에게 말하듯 구체적으로(예: "이차항 계수가 0인 경우를 따로 안 봄", "구간 끝점을 포함할지 판단 안 함"). '개념 부족' 같은 막연한 이름 금지.
- 사례 수(cases)와 서로 다른 시험지 수(exams)를 정확히 센다. 많은 순으로.
- 각 원인마다 대표 사례 2개(exam, no, 학생 흔적 요약 한 줄)를 붙인다.
- 각 원인마다 "이 함정을 실제로 작동시키는 문제의 조건" 을 한 줄로 적는다(다음 단계에서 문제를 만들 때 쓴다). 사례에서 드러난 조건만.

출력 `catalog.json`:
{"unit": "...", "total_cases": N, "causes": [{"name": "...", "cases": n, "exams": m, "what": "어디서 어떻게 어긋나는가 2문장 이내", "trigger": "함정이 작동하는 문제 조건", "examples": [{"exam": "...", "no": 0, "trace": "..."}], "item_refs": ["exam#no", ...]}], "other": n}
모든 사례는 정확히 한 원인(또는 other)에 들어가야 한다 — item_refs 합 + other = total_cases.

`catalog.json` 은 반드시 UTF-8 로 쓴다(Python 으로 open(..., 'w', encoding='utf-8')). PowerShell Set-Content/Out-File 로 쓰지 마라 — 한글이 ? 로 깨진다.
