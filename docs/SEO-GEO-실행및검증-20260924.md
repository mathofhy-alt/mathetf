# 시험지 페이지 SEO·GEO 실행 및 검증 기록

기준일: 2026-09-24. 작업 위치: `codex/mathetf-improvements` 별도 작업공간. **운영 배포 없음.**

## 유지한 서비스 정책

- 비로그인 방문자는 기존처럼 시험지 미리보기 전 페이지를 본다.
- 로그인 회원은 문제만 있는 PDF를 무료로 받는다. 해설 포함 자료의 판매 정책은 그대로다.
- 8월 말 시험 삼아 넣은 10개 상세 페이지의 HTML 문항 발문 목록만 제거했다. 미리보기 이미지와 다운로드 경로는 제거하지 않았다.
- 무료 PDF 발급 API는 로그인 확인 후 URL을 제공한다. 유료 `exam-materials` 저장소는 비공개 버킷이며, 익명 키로 서명 URL 발급을 시도했을 때 거부되는 것을 확인했다. 이 점검은 한 자료에 대한 접근 시험이며 모든 스토리지 정책을 전수 증명하는 것은 아니다.

## 적용한 작업

1. 최신 Search Console 실적(2026-06-22~09-21)의 실제 시험지 유입 상위 URL 중 운영 DB에 미리보기와 분류 문항이 있는 30회차를 파일럿으로 선택했다. 13위 URL은 DB에 없어 다음 유효 회차로 보충했다. 다음 유효 30회차를 비교군으로 기록했고 39위 URL도 DB에 없어 제외했다. 이 기간 파일럿은 200클릭·1,364노출, 비교군은 99클릭·557노출이었다. 목록은 `src/lib/seo-exam-pilot.ts`에 있다.
2. 파일럿 페이지의 반복적인 AI 문단 대신 해당 회차의 단원·난이도 실제 집계와 2025년 같은 과목·시험 종류의 집계 비교(차이가 충분할 때만)를 표시한다. 이는 자동 분류 수치이며 교사 검수를 주장하지 않는다.
3. 상세 페이지에 같은 학교의 다른 회차 링크를 보강했다. 학교·과목 허브는 기존부터 개별 회차 HTML 링크를 제공하고 있음을 확인했다. 다운로드 CTA는 홈의 학교 필터가 아닌 정확한 회차 카드로 이동한다.
4. 2025년 공통수학1 중간·기말(45개교·966문항 / 117개교·2,546문항)과 수학I 기말(80개교·1,742문항)을 읽기 전용으로 집계한 동향 보고서 2개와 집계 방법 페이지를 추가했다. 기준일 스냅샷이며 DB가 갱신되어도 수치는 자동 변경되지 않는다. 문항 지문·정답·해설은 보고서에 없다.
5. 사이트맵에 보고서 2개와 집계 방법 페이지를 추가하고, 실제 내용 변경일을 `lastmod`에 반영했다. 시험지·학교 정적 경로 수집의 1,000행 제한도 제거했다. 미리보기가 없는 회차는 사이트맵·색인 대상에서 자동 제외하고, 미리보기가 등록되면 다시 포함한다. 점검 중 최근 등록 10건의 미리보기가 백그라운드 작업으로 생성되었고, 최종 확인 시 해설 PDF 1,311건 모두 미리보기가 있었다.
6. 시험지 상세 → 출제 도구 링크에 `origin=exam`을 실어 기존 출제 퍼널 계측과 연결했다. 출제 시작·저장·파일 응답 이벤트는 기존 측정 코드를 유지한다.

## 배포 후 측정

- 먼저 Google Search Console에서 파일럿 30개와 비교군 30개의 **배포 후 재크롤 여부**를 확인한다. 재크롤 전 미색인 상태는 결과로 판단하지 않는다.
- 재크롤된 URL의 색인 여부, 검색 노출과 클릭을 각 URL의 배포 전 수치와 비교한다. 파일럿이 원래 상위 유입군이어서 단순한 30 대 30 절대 수치 비교는 공정하지 않다. 각 군의 배포 전 대비 변화를 함께 본다.
- GA4에서 `/exam/` 상세 페이지 조회 → `qb_enter`(출제 시작, `origin=exam`) → `qb_save` 및 실제 `qb_file_response`를 본다. `qb_file_response`는 서버의 파일 응답 기록이며, 페이지 조회와 이용자의 완전한 연결은 로그인·동의·세션 유지 조건에 따라 달라질 수 있다.
- 생성형 검색에서의 노출·인용은 제공되는 플랫폼 보고서가 있을 때만 관찰한다. 색인과 출제 이용이 우선 판단 기준이다.
- 배포 후 4~6주 관찰하되, 기간만 채웠다고 결론내리지 않는다. 재크롤이 없으면 관찰을 연장한다.

## 적용 전 검증

- TypeScript 검사 및 Next.js 프로덕션 빌드 통과.
- 보고서 집계 합계와 예시 시험지 링크를 운영 DB의 읽기 전용 조회로 대조.
- 무료 PDF 로그인 요구와 유료 파일 익명 서명 URL 거부 확인.
- 로컬 화면에서 미리보기 전 페이지, 정확한 카드 이동, 보고서·상세 간 링크, 모바일 배치를 확인한 뒤 한 번에 배포할 것.
