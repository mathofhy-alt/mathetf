# 시험지 페이지 SEO·GEO 실행 제안

작성일: 2026-09-24. 대상: 운영 사이트 `mathetf.com`의 시험지 상세 페이지를 중심으로 한 검색 유입과 시험지 출제 이용 확대. 이 문서는 제안이며 배포 지시가 아니다.

## 결론

문항 전문을 공개해 색인을 얻지 않는다. 공개 페이지는 **어떤 시험인지, 실제로 보유한 자료와 문항 구성은 무엇인지, 교사가 어떻게 활용할 수 있는지**를 독자적인 분석으로 설명한다. 문제 원문·해설·원본 파일은 정해진 이용 경로에서 제공한다. SEO는 검색 결과에서 상세 페이지가 발견·선택되게 하고, GEO는 같은 공개 분석을 AI가 사실에 근거해 인용할 수 있게 한다. 별도의 “AI용 비밀 기술”이 아니라 색인, 고유한 정보, 신뢰할 만한 출처가 공통 기반이다.

## 확인한 현재 상태

- 9월 21일자 Google Search Console 보고서에서 `/sitemap.xml` 제출 범위는 색인 84개, 미색인 911개다. 미색인 중 **발견 후 미크롤 516개**, **크롤 후 미색인 389개**, 사용자 선택 표준 URL이 없는 중복 6개다. 서로 다른 문제이므로 별도 대책이 필요하다.
- 8월 29일 문항 전문을 넣은 10개 파일럿 중 조사한 세 URL의 마지막 구글 크롤은 6월 23일·7월 2일·7월 4일이었다. 따라서 파일럿의 미색인만으로 문항 전문의 효과를 판정할 수 없다. 반면 다른 시험지 한 건은 9월 22일에 크롤된 뒤에도 미색인이라 **재크롤 요청만으로 전체 문제가 해결된다는 근거도 없다**.
- 운영 시험지 상세에는 고유 제목·canonical, 시험 구성, 단원·난이도, AI 분석, 미리보기, LearningResource·Breadcrumb 구조화 데이터가 이미 있다. `/exam` 중복 형식 URL의 대표 페이지 리다이렉트, robots, 사이트맵과 이미지 사이트맵도 이미 있다. 이를 다시 만드는 일은 우선순위가 아니다.
- 표본 페이지의 분석 문단은 통계 수치를 서술한 뒤 일반적인 학습 조언으로 끝난다. 검색엔진·사용자 모두에게 추가 가치를 주려면 **회차마다 실제로 다른 교사 관점의 분석**이 필요하다. 자동 문구의 양을 늘리는 것은 해결책이 아니다.
- 비로그인 방문자에게 시험지 미리보기 전 페이지를 보여주고, 로그인 회원에게 문제만 있는 PDF를 무료로 제공하는 방식은 현재의 의도된 서비스 정책이다. 이 공개 범위와 무료 제공 정책은 그대로 유지한다.

## 실행안과 우선순위

### P0. 문항 텍스트 노출만 정리하고 기존 무료 이용 정책 유지

1. 배포 대기 중인 10개 시험의 HTML 발문 목록 제거를 반영한다. 나머지 시험으로 확대하지 않는다.
2. 비로그인 전체 미리보기, 로그인 회원의 문제만 있는 PDF 무료 제공을 유지하고 시험지 상세에서 실제 이용 흐름을 검증한다.
3. 해설 등 별도 권한이 필요한 파일의 접근 제어를 확인한다. 문제 원문·해설을 메타 설명이나 JSON-LD에 추가로 넣지 않는다.

### P1. 시험지 상세의 고유 가치 만들기 — 상위 30회차부터

기존 분석 글을 늘리는 대신 검색 수요·기존 방문·출제 이용이 높은 30회차를 고른다. 각 페이지에 검증 가능한 요소만 넣는다.

- 시험 식별: 학교, 연도, 학년, 학기, 시험 종류, 과목, 실제 보유 파일·문항 수.
- 출제 특징: 단원별·난이도별 비중에서 **이 회차에서 특별히 두드러지는 사실 2~3개**. 가능할 때만 같은 학교의 전년도 또는 전학기와 비교한다. 비교 자료가 없으면 비교 문장을 쓰지 않는다.
- 교사 활용: 특정 단원 보강 또는 재출제에 어떻게 이용할 수 있는지 1~2문장. 문항의 식·정답·해설은 싣지 않는다.
- 근거와 신뢰: 자료의 검수 상태, 분석에 쓴 문항 수, 단원·난이도 분류 기준과 최종 검수일을 정확히 표시한다. 실제로 검수하지 않은 내용에 “교사 검수” 표시를 붙이지 않는다.

자동 생성 분석은 사실 검증과 반복 문장 검출을 통과한 것만 사용한다. 오류·근거 부족 페이지에는 억지로 설명을 채우지 않는다. 30개를 먼저 개선하고 같은 학년·과목의 비교군 30개를 유지한다. **Google이 변경 후 재크롤한 URL끼리** 색인과 검색 노출을 비교한 뒤 확대한다.

### P2. 발견 후 미크롤 516개를 위한 링크 구조

기존 제안서의 관련 시험지 링크를 우선 구현한다. 같은 연도가 없는 631개 상세 페이지에서도 같은 학교·과목의 가까운 회차 또는 학교·과목 허브로 이동할 수 있게 한다. 학교·지역·과목 페이지에서는 주요 시험지로 서버 HTML의 설명적인 링크를 제공한다. 사용자가 같은 회차 자료를 찾는 다운로드 버튼도 정확한 자료 ID로 연결한다. 현재 홈의 학교 필터로 보내는 경로는 회차를 다시 찾게 만든다.

모든 1,261개 URL에 임의의 링크를 쌓지 않는다. 방문자에게 실제로 관련된 자료만 연결하고, 해설이 없거나 미리보기가 없는 얇은 상세 페이지는 사이트맵·색인 대상으로 적합한지 다시 분류한다.

### P3. 문항을 공개하지 않는 인용 가치 만들기

개별 시험지와 별도로 **보유 DB 기반의 공개 출제 동향 보고서**를 소수 발행한다. 예를 들면 “2025학년도 고1 공통수학1 기말고사: 분석 대상 학교 수, 자주 출제된 단원, 난이도 분포와 전년도 변화”다. 실제 집계가 완료된 주제만 발행하고 표본 수, 기간, 분류 기준, 누락 범위, 검수자를 표시한다. 보고서에서 근거가 된 학교·시험지 상세로 연결하고, 상세 페이지에서는 관련 보고서로 돌아갈 수 있게 한다.

이 보고서는 AI가 인용할 수 있는 **수학ETF만 가진 원자료 기반의 사실**을 공개하면서도 문제 문장과 해설은 보호한다. 대량의 학교명 치환 페이지나 AI가 쓴 일반 공부법 글은 만들지 않는다.

### P4. 기술 신호와 측정

- 사이트맵에는 대표 시험지 URL만 넣고, 실제 분석·미리보기·링크가 바뀌었을 때만 `lastmod`를 갱신한다. `changefreq`·`priority` 조정에 시간을 쓰지 않는다.
- 실제 페이지 HTML과 구조화 데이터의 무료/유료 범위, 문항 수, 과목 정보가 일치하는지 점검한다. 새로운 GEO 전용 스키마나 `llms.txt`를 색인 해결책으로 만들지 않는다.
- 배포 후에는 개선한 30개와 비교군 30개의 **재크롤 여부를 먼저 확인**한다. 재크롤 전 미색인은 실험 결과로 세지 않는다. 재크롤 후 색인율·노출·검색 클릭과 GA4의 `시험지 상세 → 출제 시작 → 파일 다운로드` 완주율을 본다.
- GEO는 Google Search Console의 생성형 검색 성과 보고서가 제공되면 활용하고, Bing Webmaster Tools의 AI Performance, ChatGPT 추천 유입도 별도 관찰한다. 인용 수 자체보다 실제 출제 이용으로 이어진 방문을 우선 지표로 삼는다.

## 이번 배포에 묶을 순서

1. 문항 전문 10개 제거와 기존 미리보기·무료 PDF 이용 흐름 확인, 해설 파일 접근 점검.
2. 상위 30회차의 사실 검수된 상세 분석과 링크 개선. 사이트맵 수정일 반영.
3. 원자료 기반 출제 동향 보고서 2~3개와 분류·검수 기준 페이지.
4. 한 번에 배포한 뒤 Search Console에서 재크롤을 확인하고 4~6주 관찰. 그 전에는 1,261개 전체를 일괄 개편하지 않는다.

## 근거

- Google Search Central, [생성형 AI 검색 최적화 안내](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide): 색인 가능한 고유·유용한 콘텐츠가 기반이며 `llms.txt`나 특수 스키마는 필요하지 않음.
- Google Search Central, [AI 기능과 웹사이트](https://developers.google.com/search/docs/appearance/ai-features): AI 검색의 지원 링크에는 일반 검색 색인 자격이 먼저 필요함.
- Google Search Central, [크롤 가능한 내부 링크](https://developers.google.com/search/docs/crawling-indexing/links-crawlable): 문맥에 맞는 HTML 링크가 페이지 발견에 도움.
- Google Search Central, [사이트맵의 정확한 수정일](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap): `lastmod`는 실제 변경과 일치해야 함.
- OpenAI, [게시자 FAQ](https://help.openai.com/en/articles/12627856-publishers-and-developers-faq): ChatGPT 검색 포함에는 OAI-SearchBot 접근과 유입 측정이 관련됨.
